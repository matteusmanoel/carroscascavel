# O schema Postgres continua se chamando facilcar

A Carros Cascavel nasce com um Postgres novo e vazio. O schema interno permanece `facilcar`, o mesmo nome das migrations e do SQL já escritos. O visitante não vê esse nome. Rebatizá-lo obrigaria reescrever a base antes do primeiro site, sem mudar a marca. O isolamento entre as empresas é o banco novo, sem estoque, leads ou documentos da FácilCar.
